# Bela Tracker

Bela Tracker is an Android application designed for tracking Bela matches and scores.

The app provides a simple way to record match results and keep track of the current score during a game.

## Features

- **Match tracking** — record Bela match results and scores
- **Score tracking** — keep track of the current match score
- **Simple interface** — focused on quick and easy score entry

## Tech Stack

- **Language** — Kotlin
- **UI** — Jetpack Compose
